# Changelog

## 1.0.0 — 2026-10-11

First release.

- Cartoon butt above the prompt in the terminal and the desktop Code tab; click it for a hand slap
- Eight slappers: hand, slipper, whip, riding crop, belt, ruler, fly swatter, frying pan, each with its own sprite, mark and synthesized sound
- Nine butts: thong, no tattoo, Claude tattoo, OpenAI tattoo, shorts, boxers, jeans, robot, peach
- Swing, jiggle, reddening, marks, insults and COMBO ×N on fast series
- Claude gets the tally once, with your next message, as a note only the model reads
- Folds into one line; keys 1–8 slap, 9 swaps the butt, 0 toggles the sound
- English and Russian, following the language of your messages; `/slap lang` pins it
- `/slap`, `/slap mute`, `/slap reset`, `/slap skin [name]`, `/slap lang en|ru|auto`
